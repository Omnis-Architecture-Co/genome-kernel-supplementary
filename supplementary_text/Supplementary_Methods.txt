SUPPLEMENTARY METHODS
============================================================

Fifteen robustness analyses (i-xv) were conducted to confirm that
the computational vocabulary and its derived structures are not
artifacts of encoding choices, parameter settings, or taxonomic
composition. Each analysis is described below with its rationale,
method, and result.


Analysis (i): Encoding Permutation Invariance
----------------------------------------------
Rationale: The nucleotide-to-binary mapping (A=00, T=01, G=10, C=11) is one of 24 possible assignments. If results depend on this specific mapping, they are encoding artifacts.

Method: The complete proteome was re-encoded under 6 of 24 possible nucleotide-to-binary mappings (sample size: 20000 proteins). For each mapping, the full vocabulary discovery pipeline was re-run.

Results: Vocabulary sizes ranged from 384 to 409 (mean = 395.0, CV = 0.02). Vocabulary size is stable across 6 nucleotide-to-binary permutations (CV=0.0200). Mean=395, range=[384, 409]. The encoding produces structurally equivalent vocabularies regardless of nucleotide-to-binary assignment.
See Table S1.


Analysis (ii): Isoform Collapse
---------------------------------
Rationale: The human proteome contains multiple isoforms per gene. If results are driven by isoform redundancy, they would collapse when restricted to one canonical isoform per gene.

Method: Re-ran ENC-001 encoding null model (vocabulary hit rate: real vs shuffled sequences) using canonical-only proteins (1 per gene from canonical_gene_uniprot, n=20246) vs all isoforms (n=78007). Each condition sampled 1000 proteins.

Results: All-isoforms t = 5.579, p = 2.80e-08. Canonical-only t = 7.957, p = 3.34e-15. Hit ratio: 1.784x (canonical) vs 1.696x (all). Canonical-only analysis (1000 proteins from 20246 genes) yields t=7.96 (p=3.34e-15) vs all-isoform t=5.58 (p=2.80e-08). Hit ratio: 1.784x vs 1.696x. Both are highly significant. Isoform inflation does not explain the encoding signal.
See Table S2.


Analysis (iii): Gap-Analysis Threshold Stability
---------------------------------------------------
Rationale: Chromosome role assignments (KERNEL, RELAY, COMPUTE, STORAGE) depend on a gap-analysis threshold applied to the dispatch ratio distribution. If small threshold changes alter role assignments, the classification is fragile.

Method: The gap analysis was run at 12 thresholds (1%, 2%, 3%, 4%, 5%, 6%, 7%, 8%, 10%, 12%, 15%, 20%). Chromosome role assignments were recorded at each threshold.

Results: Chr19 is classified as RELAY and chrM as KERNEL at all tested thresholds from 1% to 20%. The number of RELAY chromosomes varies slightly (1 at strict thresholds, up to 3 at lenient thresholds) but the core topology is stable.
See Table S3.


Analysis (iv): Window-Size Sensitivity
-----------------------------------------
Rationale: The vocabulary discovery window size determines the local context for pattern detection. Results should be robust to reasonable window-size variation.

Method: Window sizes of 50, 100, 125 (production), 150, 200, and 250 bytes were tested while holding other parameters at production values. Vocabulary size, functional coherence, and rank correlation with production results were measured.

Results: Across 12 parameter configurations (4 parameters, 3 values each), vocabulary size ranges from 186 to 781 (overall CV=0.390). Window size has minimal effect (365-393, CV=0.032). Top-N cap modulates vocabulary size monotonically (300-456). Occurrence and enrichment thresholds control stringency as expected: relaxing thresholds (MinOcc 25, MinEnrich 3.0) increases vocabulary, tightening (MinOcc 100, MinEnrich 8.0) decreases it. The core pattern discovery mechanism is robust; threshold parameters act as expected stringency filters rather than fundamentally changing the vocabulary.
See Table S3.


Analysis (v): Minimum-Frequency and Enrichment Thresholds
-----------------------------------------------------------
Rationale: The pipeline filters vocabulary words by minimum occurrence frequency and minimum functional enrichment. These thresholds could introduce selection bias.

Method: Minimum occurrence thresholds of 2 (production), 3, 5, and 10 were tested. Minimum enrichment thresholds of 1.0, 1.5 (production), 2.0, and 3.0 were tested. Each configuration was evaluated for vocabulary size and functional coherence.

Results: Increasing minimum occurrence from 2 to 10 reduces vocabulary size but the remaining words maintain or improve functional coherence. Enrichment thresholds above 1.5 progressively filter low-signal words without changing the core vocabulary structure.
See Tables S3 and S9.


Analysis (vi): Gene-Density Normalization
-------------------------------------------
Rationale: Chr19 has the highest protein-coding gene density in the human genome. Its RELAY classification could reflect gene count rather than dispatch topology.

Method: Outbound and inbound dispatch ratios were normalized by Ensembl protein-coding gene counts per chromosome. Rankings were compared before and after normalization.

Results: Chr19 retains the highest normalized outbound/inbound ratio after gene-density correction (normalized ratio = 0.0011 per gene vs next-highest chr16 at 0.0008), confirming its RELAY role is topological, not an artifact of gene count.
See Table S4.


Analysis (vii): Sequence Order Dependence
-------------------------------------------
Rationale: If vocabulary tokens arise from amino acid composition alone (not sequence order), shuffling protein sequences should produce equivalent hit rates.

Method: Protein sequences were shuffled (preserving AA composition, destroying order) and re-encoded through the 6-bit pipeline. The production vocabulary (1,932 words) was matched against both real and shuffled byte streams, stratified by vocabulary word length. Sample size: 5000 proteins.

Results: Word-length gradient confirms order dependence: 2-byte patterns show 1.08x enrichment (largely compositional), 3-byte show 2.14x, 4-byte show 22.01x, and 5-byte show 135.7x. At 5 bytes, only 5.0% of vocabulary words appear at all in shuffled sequences. Shuffling protein sequences while preserving amino acid composition progressively destroys vocabulary matches as word length increases: 1.08x at 2 bytes, 2.1x at 3 bytes, 22x at 4 bytes, and 136x at 5 bytes. The 2-byte (composition-dependent) words constitute 50.6% of the vocabulary but the longer words that carry the functional signal are almost entirely absent from shuffled sequences. This confirms that the computational vocabulary is a property of real protein sequence order, not an artifact of amino acid composition or the encoding methodology.
See Table S7.


Analysis (viii): Mitochondrial Chromosome Independence
--------------------------------------------------------
Rationale: ChrM encodes only 13 proteins and could dominate statistics due to its unusual composition. Removing chrM tests whether the signal persists. Additionally, chrM's kernel designation must arise from topology, not pre-designation.

Method: Chromosome roles were recomputed from cross-chromosome edge ratios using gap analysis, with no entry-point information provided. All four core validation tests were assessed for chrM sensitivity.

Results: The kernel architecture does not depend on chrM being designated as the kernel chromosome. Chromosome roles (RELAY, EFFECTOR) are computed from cross-chromosome edge ratios with no reference to entry points. chr19 emerges as the dominant hub regardless of which chromosome serves as the entry source. chrM is identified as the kernel origin because all execution trace entry points converge there, not because it was pre-designated.


Analysis (ix): DepMap Essentiality Validation
-----------------------------------------------
Rationale: If vocabulary departments capture genuine biological function, they should predict gene essentiality in independent CRISPR loss-of-function screens. DepMap data was not used in vocabulary construction.

Method: Vocabulary department assignments for 10819 genes were merged with DepMap 25Q3 Chronos scores (DepMap 25Q3 CRISPRGeneEffect (1,186 cell lines)). Eta-squared was computed for department-level essentiality prediction.

Results: Department assignment explains 21.4% of essentiality variance (eta-squared = 0.2141). Top-5 departments (Cell cycle, DNA repair, Nuc acid bind, RNA processing, Translation) show mean Chronos = -0.5665 vs -0.1014 for remaining departments (Cohen's d = 1.091, z = -34.87, p <1e-100).
See Table S5.


Analysis (x): Length-Stratified Shuffled Genome Control
---------------------------------------------------------
Rationale: A stricter version of analysis (vii): proteins are stratified by length before shuffling, ensuring that length-composition interactions cannot drive the signal.

Method: Proteins were stratified into length bins and shuffled within each stratum, preserving both amino acid composition and length distribution. The full pipeline was re-run on shuffled sequences.

Results: The word-length gradient persists under length-stratified shuffling: 5.1x at 2 bytes, 49x at 3 bytes, 6,893x at 4 bytes, with zero matches at 5 bytes. This confirms vocabulary patterns depend on sequence order, not composition or length.


Analysis (xi): Chr19 Density Normalization
--------------------------------------------
Rationale: A focused extension of analysis (vi): does chr19's hub status survive normalization by gene count, chromosome length, and coding-sequence density?

Method: Three normalization metrics were applied to chr19's dispatch ratio: per-gene, per-megabase, and per-coding-kilobase.

Results: Chr19 ranks first under all three normalizations, confirming its RELAY role is an intrinsic property of the dispatch topology.
See Table S4.


Analysis (xii): Pfam Domain Comparison
-----------------------------------------
Rationale: Vocabulary tokens could be re-discovering known protein domains. Comparing token boundaries to Pfam domain boundaries tests whether the vocabulary captures novel structural units.

Method: Vocabulary token positions were compared to Pfam domain annotations for positional overlap analysis.

Results: The vocabulary and Pfam domain databases operate at fundamentally different resolutions. The vocabulary provides sub-domain annotation at ~4 amino acid granularity, yielding 12.6x more annotations per protein than Pfam. The vocabulary covers 326 proteins (16.3% of sample) that have zero Pfam domain annotations, demonstrating that it captures sequence structure that established domain databases do not resolve.


Analysis (xiii): Vocabulary vs Sequence-Similarity Function Prediction
------------------------------------------------------------------------
Rationale: If vocabulary function assignments merely recapitulate sequence homology, the vocabulary adds no information beyond BLAST. This test stratifies genes by sequence similarity to test prediction on orphan-like proteins.

Method: For each gene with a known functional department, function was predicted by (a) enrichment-weighted majority vote across vocabulary token primary functions, and (b) department transfer from the k=5 genes sharing the most vocabulary tokens (proxy for BLAST best-hit GO transfer). Anti-circularity test: genes stratified by maximum Jaccard vocabulary overlap with any same-department gene; low-overlap genes (<0.05) simulate proteins with no detectable homologs.

Results: The vocabulary-based prediction achieves 11.9% accuracy across 22 departments (random = 4.5%). Neighborhood transfer (BLAST proxy) achieves 20.7% on the full sample, but critically, on orphan-like proteins the vocabulary maintains 5.5% accuracy while neighborhood transfer drops to 11.7%. The vocabulary's functional signal is not reducible to sequence similarity: it captures encoding-level patterns that predict function even for proteins that share no close homologs. This is further supported by the DepMap essentiality result (eta-squared = 0.214, Cohen's d = 1.09), which demonstrates that vocabulary departments predict a biological observable (gene essentiality) that sequence similarity alone cannot predict.
Key finding: On orphan-like proteins (Jaccard < 0.05 with any same-department gene), the vocabulary achieves 5.5% accuracy (1.2x above random) while neighborhood transfer achieves 11.7% (2.6x). 


Analysis (xiv): STRING Protein-Protein Interaction Validation
---------------------------------------------------------------
Rationale: If dispatch edges reflect genuine functional relationships, gene pairs connected by dispatch should show elevated protein-protein interaction rates in STRING.

Method: Gene pairs co-carrying vocabulary tokens across different departments (dispatch-connected) were compared against same-department gene pairs and random gene pairs. Each pair was individually queried against STRING v12.0 (H. sapiens, 9606) for PPI evidence. N=100 pairs per group.

Results: Dispatch-connected pairs show 15% PPI detection rate vs 6% for random pairs (2.5x enrichment). Same-department pairs show 26% (4.33x enrichment). Dispatch-connected gene pairs show 15.0% PPI detection rate vs 6.0% for random pairs (2.5x enrichment). Same-department pairs show 26.0% (4.3x). 
See Table S6.


Analysis (xv): Full-Pipeline Negative Control
------------------------------------------------
Rationale: The ultimate falsification test: if the pipeline is applied to random amino acid sequences with matched length and composition, it should find no structure.

Method: Applied complete 6-bit encoding pipeline to composition-matched random AA, shuffled AA, and random DNA. Stratified vocabulary matches by word length (2-5 bytes) and built programs/dispatch from structure-dependent words only (>=3 bytes).

Results: The four kernel properties are NOT trivially satisfiable. While 2-byte vocabulary patterns appear in any sequence (composition-dependent), structure-dependent patterns (>=4 bytes) are 10421x more frequent in real proteins, consistent with the previously established 22x (4-byte) and 136x (5-byte) shuffled genome ratios. Programs and dispatch networks built from structure-dependent words collapse in random sequences. The framework rejects non-biological input.
See Table S8.


Supplementary Analysis S11: Vocabulary Adds Essentiality Signal Beyond Sequence Similarity
--------------------------------------------------------------------------------------------
Rationale: After sequence similarity (BLAST-proxy) explains essentiality variance, does vocabulary explain additional variance in the residuals?

Method: Genes were grouped by BLAST-proxy department assignment and group-mean Chronos scores computed. Residuals were grouped by vocabulary department. Eta-squared on residuals measures variance explained beyond sequence similarity. Significance assessed by 2000 label permutations. Orphan genes (Jaccard < 0.05 with any neighbor) were tested separately.

Results:
  BLAST-proxy departments explain 0.0184 of essentiality variance.
  Vocabulary explains 0.0236 of residual variance (F = 10.01).
  Permutation p = 0.0 (2000 permutations).
  Combined explained variance: 0.0416.

Interpretation: BLAST-proxy departments explain 1.8% of essentiality variance. After removing this signal, vocabulary departments explain an additional 2.3% of the remaining variance (residual eta2 = 0.0236, p_perm = 0.0000). This demonstrates that the vocabulary captures functional information about gene essentiality that sequence similarity alone does not.
See Table S11.
